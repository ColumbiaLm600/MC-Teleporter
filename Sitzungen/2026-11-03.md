## Erledigt

- Server-Prüfungen abgeschlossen:
  - Command-Blöcke sind erlaubt
  - Download von GitHub per `wget` klappt
  - CC: Tweaked 1.113.1 (CraftOS 1.9), Minecraft 1.20.1 Forge
- End-Transitportal von Hand getestet, Spieler landet genau am Ziel:
  `/setblock X Y Z minecraft:end_gateway{ExitPortal:{X:..,Y:..,Z:..},ExactTeleport:1b}`
- Wichtige Änderung am Konzept: Jede Station besteht jetzt aus **zwei Computern**,
  damit **jeder Spieler** telefonieren kann (Command Computer können nur Operatoren bedienen):
  - **Telefon** = normaler Computer, nur Bildschirm und Tastatur
  - **Steuerung** = versteckter Command Computer mit Ender-Modem, macht die eigentliche Arbeit
  - Verbindung per **Netzwerkkabel** (Variante A). Die Steuerung nimmt Tastendrücke nur über das Kabel an.
  - Commandblock als Peripheriegerät wurde verworfen (Sicherheitsloch: beliebige Befehle möglich)
- Positionen werden als **feste Koordinaten** (wie in F3) eingegeben (Variante A)
- MVP programmiert, auf GitHub hochgeladen und **im Spiel erfolgreich getestet**:
  - `install.lua`: ein Installationsprogramm für beide Computer, erkennt selbst Telefon oder Steuerung
  - `telefon.lua`: Bildschirm und Tastatur für alle Spieler
  - `steuerung.lua`: wählen, klingeln, annehmen (manuell J/N oder automatisch), Portal für 10 Sekunden

Installation im Spiel (auf jedem Computer, zuerst Steuerung, dann Telefon):
`wget run https://raw.githubusercontent.com/ColumbiaLm600/MC-Teleporter/main/install.lua`
